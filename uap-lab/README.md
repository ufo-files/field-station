# UAP Training Lab

Independent local browser app: http://hackrf.local:8091/ (or the station IP, port 8091).
Service: `systemctl --user status uap-lab.service`.

Videos appear automatically from `/home/hackrf/t7/training-data` on the external SSD; browser uploads work too. The `PURSUE` folder points to the downloaded collection without duplicating its storage. Drag a box around each target, or tap its two opposite corners. Touching a playing frame pauses it immediately; native image refreshes never replace a frame during a gesture. Extra fingers are ignored and drawing can finish beyond the image edge; scrub to additional moments to add more selections. Numbered selections survive reloads. **Next** saves all selections and advances. **Omit video** removes a video from the training queue and excludes its labels from new models while keeping its original file. Existing immutable model versions remain unchanged; Done creates the next model without omitted videos. Next saves the label, permanently marks the video reviewed, and advances to the next unreviewed video. Reviews are indexed by content checksum so identical videos stay reviewed across renames, duplicate drops, browser uploads, reloads, and restarts. Folder intake uses content-based identity; genuinely changed content at an old filename enters the queue as a new video. These rules apply to all video sources, not only PURSUE. **Done** saves the reusable versioned model and selects it for live and automated processing. Labels default to anomalous; known alternatives are under the label menu. Testing and live viewing have their own tabs.

The **Live camera** tab displays the camera preview and tags from the saved model. Three consistent analyzed frames at correlation 0.97 confirm each anomalous track independently. Multiple simultaneous targets and newly appearing targets get independent confirmation. The camera station retains its original native video, buffered pre-roll/post-roll, original matched frames, and RF spectrum logs. New events have a 90-second cooldown; ongoing matches extend a motion-window recording. Model matches use the exact source JPEG and its checksum, rather than whichever camera frame happens to exist after inference finishes. Once the recording is assembled, the frozen event model processes every native frame and exports clips, with RF and session metadata copied beside the run. Model suggestions remain separate from human confirmation. **Pause tagging** stops new model detections while leaving the preview available.

Reusable models are stored in `models/<version>/model.json` with their native exemplars, and `active-model.json` selects the current version. Each run snapshots that version. An automation entry point is `.venv/bin/python process_video.py /path/to/video.mp4 [--model VERSION] [--rf-log /path/to/rf.jsonl]`; it uses the active saved model by default. No model is silently retrained during processing.

The first model is an explicit multiscale normalized appearance matcher, not a newly trained neural object detector. Training snapshots labeled native crops into an immutable version; stronger matches to known alternative classes suppress overlapping target matches. It works best on visually similar targets and scales. Add varied examples and use separate videos to assess performance. Scores are correlation, not calibrated probabilities. The live model is used by the lab bridge; it does not replace the station’s existing bird/airplane classifier.

## Live sessions and model publishing

Live preview runs independently of inference and keeps updating during a model scan. The view uses a steady Live connection indicator. Full screen keeps the image and model overlays aligned, including an iPad viewport fallback. Fullscreen controls fade after five seconds without interaction; target boxes and the active recording badge remain visible. Touch or pointer movement restores the controls. Tagging stays enabled; no pause-tagging control is shown. **Start session** begins a manual video/RF recording; **Stop session** finalizes the selected current session. Manual sessions retain the station's two-hour maximum. Automatic motion, RF, and schedule triggers are disabled; confirmed model matches remain the only automatic capture source. Existing model detections may annotate a manual session.

Live matching uses a bounded coarse search and native-pixel verification, rechecks recently matching templates, and cycles through the complete saved template bank. It can return multiple targets. Full template coverage is slower than the preview for large banks; `performance.bank_sweep_seconds` exposes that latency. Full native-frame evaluation still uses the complete exact appearance matcher. Preview freshness and inference freshness are separate; stale boxes are not painted on a fresh camera image.

Each **Done** model save places an immutable saved-version job in `publication/outbox/`. A background publisher pushes the model artifact, native template crops, source metadata, code, and model card to `ufo-files/uap-observation-model`, and tags it `model-<model-id>`. Full source videos, RF logs, local paths, and credentials are excluded. Newly saved models are shared automatically when publication is enabled. The exact saved crops are used, even if subsequent review data change. Upload status appears in the app. Failed uploads retain their pending commit and retry with backoff; completed receipts are stored in `publication/receipts/`. GitHub authentication uses the station user's existing Git credentials. Settings are in `publication/config.json`.

## Storage and exports

Everything is stored under `/home/hackrf/t7/uap-lab/`, outside the R100 collection:

- `videos/<id>/source`: untouched original, SHA-256 and video metadata in `video.json`; annotations and native PNG exemplars beside it. Unsupported browser formats receive a separate H.264 preview; selection still decodes the original.
- `models/<id>/`: immutable labeled appearance examples and model manifest.
- `runs/<id>/frames/`: **every decoded source frame**, lossless PNG at full native display resolution, zero frame duplication or frame-rate resampling. Filenames start at 000000001; manifests and detection indices start at zero.
- `timestamps.json`: source presentation timestamps and nominal average rate. Variable-rate timing is retained. Missing/non-increasing timestamps fail explicitly.
- `detections.jsonl`: every tested frame, its timestamp, and matches with labels, native boxes, and scores.
- `event-NNNN/frames/`: hard links to each consecutive matched frame plus one source frame before/after when present. Contiguous matches form a sequence; gaps form separate sequences.
- `event-NNNN/full-size.mp4`: full-resolution silent H.264 clip, CRF 18. Odd source dimensions receive a one-pixel pad for browser codec compatibility.
- `event-NNNN/target-NNN.mp4`: native-detail centered crop for each associated target, with 60% total context margin, a fixed even output size, edge padding, and one surrounding frame on either side. No artificial upscaling. Short track association uses label and spatial proximity; crossing objects can require review.
- `event.json`, `run.json`, `model.json`: frame boundaries, provenance, parameters, model version, and progress/errors.

Source presentation timing is preserved within MP4's 1/90000-second timebase. FFmpeg autorotation applies equally to frame selection, inference, and exports. Clips omit audio. Failed runs retain partial files for inspection. Processing is single-job, low-priority CPU and preserves 100 GiB of free space for camera capture. Large all-frame exports can require substantial storage; the app conservatively checks uncompressed frame space before extraction. Upload limit: 30 GiB per video. The service is intended for the station's trusted LAN/Tailscale network and has same-origin/token checks for writes.

## Development

Python 3.13 virtual environment at `.venv`; dependencies in `requirements.txt`. Uses the camera station's existing vendored FFmpeg and FFprobe without using its camera device or recording services. Start with `.venv/bin/python server.py`; defaults to port 8091. Override `UAP_LAB_DATA` and `UAP_LAB_PORT` for isolated tests. `UAP_LAB_RESERVE_BYTES` overrides the storage reserve.

Run `.venv/bin/python -m unittest -v test_lab` for synthetic moving-target inference, exact native frame counts, boundary exports, full-size/cropped clips, VFR timestamp checks, immutable model versions, and label validation. Browser integration check: `check_browser.py`.
