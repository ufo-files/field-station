# Phosphor no-signal test pattern

The viewport-filling grid, bars, rings, type, scan lines and vignette are responsive HTML/CSS. Inline SVG turbulence supplies procedural grain, animated with stepped transforms; reduced-motion preferences retain static grain. The central transparent engraving is the only image asset: `uap-lab/static/ufo-engraving.png`.

The engraving was generated using the built-in imagegen tool with this prompt:

Create a single sophisticated monochrome flying saucer emblem for the central medallion of a vintage television test pattern. This is ONLY the central illustration, not a screen or layout. Transparent background. A finely rendered 1950s scientific technical engraving of a mysterious lenticular metallic craft, seen slightly from below at a restrained three-quarter angle. Precise elliptical geometry, shallow elegant dome, concentric machined rim, subtle engraved crosshatching and disciplined solid-black shadow. Professional mid-century aerospace manual illustration, clean controlled line weights, archival print quality. A serious enigmatic object, not a cartoon: no face, no cute features, no windows resembling eyes, no row of round lights, no glow, no beam, no stars, no text, no border, no typography, no background or paper texture. Black and neutral gray ink only. The craft should occupy most of a wide landscape composition with generous transparent margins. Clear bold silhouette at small UI sizes, refined detail at large sizes.

Only the no-signal overlay receives the CRT treatment. Source recordings, review images, and camera recovery logic are unchanged.
