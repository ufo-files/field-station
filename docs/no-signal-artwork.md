# Phosphor no-signal test pattern

The viewport-filling grid, bars, rings, type, scan lines and vignette are responsive HTML/CSS. Inline SVG turbulence supplies procedural grain, animated with stepped transforms; reduced-motion preferences retain static grain. The central transparent engraving is the only image asset: `uap-lab/static/ufo-engraving.png`.

The alien engraving was generated using the built-in imagegen tool with this prompt:

Create ONLY a central character emblem for a vintage atomic-era television test pattern. Transparent background. A waist-up classic grey alien giving a clear thumbs-up with one hand beside its shoulder, facing the viewer, with a confident reassuring slight smile. Mid-century 1940s–1950s public-information illustration, hand-inked technical editorial engraving, disciplined black outlines, restrained crosshatching, cream-white interior highlights, sophisticated vintage print craftsmanship. Large almond-shaped black eyes, elegant elongated head, subtle simple retro flight-suit collar. Original alien character, not an existing game character. Readable and compact silhouette, thumb and hand clearly recognizable at small sizes. Professional archival broadcast emblem rather than glossy cartoon, no 3D rendering, no cute chibi proportions, no exaggerated toothy grin. Monochrome black, gray and off-white only, to receive green phosphor tint in the interface. Center character within a square composition with modest transparent margins; preserve complete head and thumbs-up hand. No text, no border, no circle, no background, no paper rectangle, no stars, no screen, no test-pattern geometry.

Only the no-signal overlay receives the CRT treatment. Source recordings, review images, and camera recovery logic are unchanged.
