# No-signal test pattern

The current test pattern is plain HTML and CSS in `uap-lab/static/index.html` and `style.css`: viewport-filling calibration grid and bars, concentric rings, a geometric flying saucer, and live text. It contains no image element, SVG, canvas artwork, image asset request, or generated raster artwork.

The known Elgato slate detector and automatic camera recovery remain unchanged. The test pattern is a display overlay; captured evidence keeps the source pixels.
